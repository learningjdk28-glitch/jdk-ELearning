# Uiverse eLearning selections

24 curated component references across seven LMS feature folders. Prepared 14 November 2026.

Start with index.html for a clickable catalog, or open the numbered folders and their Windows .url shortcuts. components.csv and components.json provide the same selection in reusable formats.

## Recommended starting set

Use the login card, blue search input, quiz radio group, indigo checkbox, bookmark, first download button, upload card, minimal switch, minimal loader, action notification, and information card. Other entries are alternatives; do not mix all visual styles on one screen.

## Scope and source access

This is a curated reference pack, not every Uiverse element and not a source-code bundle. Direct source downloading returned HTTP 403. Links and descriptions were discovered through public indexed Uiverse pages; no component code, screenshots, or live previews were downloaded. No source component was executed, visually tested, or accessibility-audited. Suitability is a design recommendation, not a verified quality ranking.

## Adopt into your LMS

1. Open a component link and visually review it on Uiverse.
2. Use Get code to copy its HTML/CSS or Tailwind implementation and its original license notice.
3. For React, convert class to className, for to htmlFor, and SVG attributes as needed. Scope CSS to prevent global collisions. Tailwind entries need your project's Tailwind setup.
4. Standardize typography, spacing, border radii, and one accent color. Use readable light surfaces for course content and a consistent dark theme if offered.
5. Wire actual authentication, search, uploads, bookmarks, settings, and submission status to your backend. UI examples alone do not implement these functions.
6. Check keyboard operation, labels, focus, contrast, mobile layouts, reduced motion, and loading/error/disabled states.

## Additional LMS work

Build or source course cards, sidebar navigation, breadcrumbs, course progress, lesson player, calendar, accessible dialogs, grading tables, and pagination separately. They are not represented here as verified ready-made Uiverse selections. Use actual completed lessons for progress; loaders do not measure learning completion.
